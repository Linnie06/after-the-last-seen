# After The Last Seen

*A 2D narrative mystery about a missing friend, hidden messages, buried secrets, and choices that change everything.*

## About the Game

**After The Last Seen** is a 2D narrative mystery game in which players investigate the disappearance of a close friend by exploring locations, examining a smartphone, collecting evidence, and uncovering secrets hidden beneath seemingly ordinary conversations.

As the investigation unfolds, players must connect clues, question conflicting accounts, and decide whom to trust. Every discovery brings them closer to the truth, but not every truth is easy to accept.

Designed to be accessible to players of all experience levels, the game focuses on emotional storytelling, exploration, and deduction rather than complex controls or technical knowledge.

## Features

- **Exploration:** Investigate illustrated environments and discover hidden details.
- **Interactive Smartphone:** Examine messages, photographs, call logs, and notes.
- **Evidence Collection:** Gather clues and connect seemingly unrelated discoveries.
- **Branching Narrative:** Make decisions that influence character relationships and story outcomes.
- **Multiple Endings:** Uncover different outcomes based on your investigation and choices.
- **Accessible Gameplay:** Enjoy the mystery without requiring prior gaming or technical experience.
- **Emotional Storytelling:** Explore themes of friendship, trust, privacy, and betrayal.

## Gameplay

The core gameplay loop revolves around five actions:

1. **Explore** locations connected to the missing person.
2. **Investigate** digital and physical evidence.
3. **Collect** clues and review discoveries in your journal.
4. **Connect** evidence to uncover contradictions and hidden relationships.
5. **Decide** how to respond to what you discover.

Each discovery brings a new piece of the mystery into focus.

## Story

A close friend has disappeared, leaving behind unanswered questions and a phone full of unexplained messages.

Three days later, a mysterious message arrives from their account:

> "If you're reading this, don't trust what they tell you. Check the photograph."

What initially appears to be a straightforward disappearance soon reveals a web of conflicting stories, hidden information, and difficult personal choices.

Can you uncover what really happened without losing sight of the person you're trying to find?

## Getting Started

The game is currently in development. Setup instructions will be added once the initial playable version is available.

### Prerequisites

- A Windows, Linux, or macOS computer compatible with the game build
- Godot 4.x for running the project through the editor

### Running the Project

Once the project files are available:

1. Clone this repository.
2. Open Godot.
3. Import the project by selecting its `project.godot` file.
4. Run the main scene from the editor.

Exact setup instructions may change during development.
